FIELD MANUAL — WIRE CUTTING

Apply the first row whose condition matches. Cut exactly the listed wires, in the order listed. Any other cut — or a listed wire cut out of order — is a strike.

  1. 1No red wires → cut the 2nd wire from the left, then the 5th wire if the slot holds 5 or 6 wires.
  2. 2The rightmost wire is yellow → cut every NON-yellow wire, working left to right.
  3. 3Exactly two blue wires → cut the 1st wire, then the last wire.
  4. 4More white wires than black wires → cut every black wire left to right; if there is no black wire, cut the 3rd wire.
  5. 5Any other arrangement → cut the first red wire, then the last wire.

FIELD MANUAL — BUTTON

Read four data points: the button cap color, the FRK indicator lamp (lit/dark), the battery count on the case, and whether the serial contains a vowel (A E I O U). While the button is held, the lamp above it shows WHITE during the first 3.0 s, RED during the next 3.0 s, GREEN during the next 3.0 s, then repeats. Judgement happens at release.

  1. 1The cap is red and the FRK lamp is lit → hold; release while the lamp is WHITE.
  2. 2The cap is red and the serial contains no vowel → hold; release while the lamp is RED.
  3. 3The cap is blue and the battery count is even (0, 2 or 4) → tap (release within 3.0 s).
  4. 4The cap is yellow and the serial contains a vowel → hold; release while the lamp is GREEN.
  5. 5Any other combination → hold; release while the lamp is WHITE.

FIELD MANUAL — ROTOR

Eight numbered lamps (1 at the top, then clockwise), each red, green, or dark. Rotate the dial with Q/E in 45° detents (1–8, wrapping 8 → 1); Space locks the dial. A lock at the wrong detent is a strike; the dial stays where it was locked and may be turned and locked again.

  1. 1No red lamp → lock at detent 6.
  2. 2An odd number of red lamps → lock at the detent equal to the lowest-numbered red lamp.
  3. 3No green lamp → lock at detent 2.
  4. 4Any other pattern → lock at the detent equal to the LOWEST-numbered green lamp.

FIELD MANUAL — MEMORY

Four keys, each printed with a label 1–4 in a fixed scrambled order; a display shows one digit per stage, drawn from the fixed four-digit sequence. Press one key per stage, in stage order:

  1. 1Stage 1: press the key at the POSITION shown on the display.
  2. 2Stage 2: press the key whose LABEL equals the display digit.
  3. 3Stage 3: if the display digit is odd, press the key at the POSITION equal to the label pressed in Stage 2; if it is even, press the key at the POSITION shown on the display.
  4. 4Stage 4: if the display digit is odd, press the key whose LABEL equals the position pressed in Stage 1; if it is even, press the key whose LABEL equals the display digit.

A wrong key is a strike and resets the module to Stage 1 with the same digit sequence. Press 1–4 while the MEMORY module is active to press the key at that position. A stage lamp 1–4 marks progress.

FIELD MANUAL — CROSS-REFERENCE

The linked pair. MA-1 and SL-1 are armed together as one linked pair, joined by the bus cable. One shared 270.00 s clock drives both displays in lockstep, with one shared strike pool and one shared rate. Three strikes or a zero clock loses the pair (PAIR FAILED); the pair is cleared only when every module on BOTH devices is defused (PAIR CLEAR). Press X to switch which device your keys act on.

Button tables. The five BUTTON rows become Table A. Use Table B when 2 or more wires have been cut on this device at the moment the button is pressed (strike cuts count); otherwise use Table A. On the linked pair, wires cut across BOTH devices are counted. Table B, first matching row:

  1. 1The battery count is odd (1 or 3) → hold; release while the lamp is GREEN.
  2. 2The cap is white → tap (release within 3.0 s).
  3. 3Any other combination → tap (release within 3.0 s).

Rotor shift. If the MEMORY module on the same device is fully solved before the dial is locked, add 1 clockwise to the detent the table gives (8 wraps to 1).

Linked pair feeds. On the pair the readings cross devices. Button selector: the table choice counts wires cut across BOTH devices. Rotor feed: SL-1's rotor takes the detent from its table row, applies the memory shift of +1 first (from MA-1's MEMORY — solved before the dial is locked), then adds P clockwise, where P is the position pressed in Stage 1 of MA-1's MEMORY in its current attempt (no feed until Stage 1 is pressed); wrap 8 → 1 at each step. LINK feed: lamp W reads the shared cut count across both devices (lit at 2 or more), lamp M reads MA-1's MEMORY solved state, and lamp B reads SL-1's own battery count (lit at 3 or 4).

LINK module. Three labelled lamps and one key. Lamp W is lit while 2 or more wires are cut on this device; lamp M is lit while the MEMORY module is fully solved; lamp B is lit while the battery count is 3 or 4. On the linked pair, the LINK feed above replaces these same-device readings. Apply the first matching row:

  1. 1The serial's last character is an even digit (0, 2, 4, 6, 8) → press the key while W and M are lit and B is dark.
  2. 2Any other serial → press the key while exactly one of W and M is lit and B is lit.

A press at any other lamp pattern is a strike. Space presses the key while the LINK module is active.

FIELD MANUAL — SEASON & SQUAD SCORE

The season. One season is a fixed roster of six devices in order: the three-device shift SB-1, SB-2, SB-3, the linked pair MA-1 + SL-1 (one shared clock, two defusals), and the final exam FX-1. Inside a season a detonation no longer restarts the shift: the device is logged as lost — a pair detonation logs both of its devices — and Enter advances to the next device; a defusal advances the same way. Strikes accumulate across the whole season. R performs the master reset: season, counters, and score return to zero.

Squad score. Score = defused devices × 200 (max 6) + max(0, 300 − season strikes × 50). Rating: S at 1000 or more, A at 800 or more, B at 600 or more, C below. Press Tab (outside an active module interaction) to open the score screen — it lists every device's state, every score line item, and the total.
